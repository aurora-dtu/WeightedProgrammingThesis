            structure WDP (𝒲 : Type u_1) (S : Type u_2) (A : Type u_3) [Zero 𝒲] :
            Type (max (max u_1 u_2) u_3)

            A weighted decision process (WDP) is a tuple 𝑀 = (𝒲,ℛ,S,A,τ) and is comprised of

            1. The monoid of weights 𝒲, a monoid with zero.
            2. The naturally ordered, 𝜔-continuous 𝒲-module ℛ of rewards, such that the natural order of ℛ is a complete lattice.
            3. The state space S, an arbitrary set.
            4. The action space A, an arbitrary set.
            5. the state transition τ : S × A → S → 𝒲, such that τ(𝑠,𝑎)(𝑠′) ≠ 0 for at most countably many 𝑠′.
            6. the reward function ρ : S → ℛ.
            • τ : S → A → S → 𝒲
            • τ_countable (s : S) (α : A) : Countable ↑(Function.support (self.τ s α))
